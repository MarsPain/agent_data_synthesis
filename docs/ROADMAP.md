# Roadmap

Current work is tracked in the [local issue tracker](../.scratch/README.md).
The active sequence is Agent-first cutover: one public entrypoint, removal of
legacy runtime and readers, canonical documentation, clean installation, and
verified run, resume, replay, and review import. The operator directed this
work under an explicit exception to formal dataset acceptance. The unchanged
cohort still needs independent direct-human review for that claim.

Future work may improve task quality, review coverage, or downstream dataset
consumption, each with its own evidence and authorization. Historical plans
remain in [docs/PLANS.md](PLANS.md).
